# Estrutura do Projeto DevTech

Este diretório contém os scripts de automação e a estrutura organizacional das pastas dos setores da empresa **DevTech**.

---

## 📁 Estrutura de Diretórios

```text
devtech/
├── RH/             # Documentos e arquivos relacionados a Recursos Humanos
├── financeiro/     # Arquivos e relatórios do setor Financeiro
├── projetos/       # Gestão e acompanhamento de Projetos
└── docs/           # Documentos contendo contratos e manuais


devtech.sh      # Script principal de automação do ambiente

---

🚀 Como Executar o Script

Para executar o script de automação devtech.sh no seu ambiente Linux/Bash, siga os passos abaixo:
1. Conceda permissão de execução:Bashchmod +x devtech.sh
2. Execute o script:Bash./devtech.sh
