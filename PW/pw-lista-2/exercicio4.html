1. O que é pirâmide de teste

Entenda porque a pirêmide de teste é importante para a qualidade do software.

  • A pirâmide de teste ajuda a identificar problemas em diferentes níveis do desenvolvimento
  • Visualização clara do nível de cobertura de testes
  • Planejamento eficiente dos testes

2. Onde aplicar testes manuais na pirâmide de testes

Quais testes devem ser executados manualmente?

  • Exploração (exploratory testing)
  • Testes de usabilidade
  • Testes de aceitação

3. Onde aplicar testes automatizados na pirâmide de testes

Quais testes devem ser executados automaticamente?

  • Teste de fluxo completo (END-TO-END)
  • Usando frameworks de teste
  • Uso de linguagem de programação para automação
